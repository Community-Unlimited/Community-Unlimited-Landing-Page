GitHub access Not connected

Publishing writes content.json straight to your repo, which makes Vercel rebuild the site. You need a token with write access to do that.

Kept in this browser tab only (sessionStorage). Closing the tab forgets it.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only this repo.
  3. Permissions → Repository → Contents: Read and write.
  4. Set a short expiry — 30 days is plenty.
This page is public. Anyone can open /admin, though they can do nothing without a token. Before you share the site, turn on Vercel password protection for this path — Project → Settings → Deployment Protection.
